Setup

Two minutes, three steps.

  1. Add the bot. Click Add to Discord and approve. It does not ask for Administrator.
  2. Run /setup wizard. Pick the welcome channel, logs and roles from menus. Then /ticket setup and /antinuke preset standard if you want them.
  3. Move the JARVIS role up. Drag it above the roles it should manage, then try /help.

FAQ

Common questions

Is JARVIS free?

Yes. Only the optional custom bot profile costs money.

Which permissions does it need?

No Administrator. Only what features need: Manage Channels, Manage Roles, Ban and Kick, View Audit Log, Manage Messages, Manage Webhooks and similar.

Where can it play music from?

SoundCloud, Spotify songs, albums and playlists, and direct audio links. /247 enable keeps it in voice all day.

How does antinuke work?

You set how many bans, kicks, deletes and so on are allowed in how many seconds, and the punishment. If someone goes over, JARVIS acts and restores what it can.

What data do you store?

Only what features need: settings, levels, tickets. Read the privacy policy. Data is deleted when the bot leaves your server.

Something is broken. Who do I ask?

Join the support server. A person answers.
