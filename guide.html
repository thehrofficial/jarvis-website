Server guide

Everything you need to set JARVIS up in your server, step by step. You need the Manage Server permission. Type / in Discord and pick the command. Options marked optional can be skipped.

Easiest way: the web dashboard

Almost everything below can also be set with clicks on the dashboard. Log in with Discord, pick your server and use the pages on the left: Welcome, Logs, Automod, Warnings, Tickets, Levels, Server stats, Invite rewards and more. It shows what is not set up yet and has a small helper you can ask in your own words. Only people with Manage Server can change things, and antinuke can be changed by the server owner only. Try the demo first, no login needed.

1. First steps

  1. Add JARVIS with the Add to Discord button.
  2. In Server Settings → Roles, drag the JARVIS role above the roles it should give or manage (autorole, level roles, ticket staff). A role that is above JARVIS cannot be given by it.
  3. Type /help to see all commands.

2. Welcome and leave messages

  1. /setup welcome channel:#welcome and set title, message and image.
  2. In the message you can use {user} {username} {server} {count}. For a new line type \n.
  3. Use editor for a big text box, and test to preview it.
  4. Same for leaving: /setup leave.

3. Tickets

  1. /ticket setup: choose the staff role (up to 3 roles), the log channel and the panel channel.
  2. /ticket addtype: add a ticket type with its own emoji, description, category and welcome text. Change it later with /ticket edittype.
  3. /ticket panel: sends the panel with the buttons or dropdown. It updates by itself when you change something.
  4. Button colour: color: in /ticket setup (all buttons) or in /ticket addtype / /ticket edittype (one type). Blue, grey, green or red. Colours need style:Buttons; a dropdown has none.
  5. Ask people questions before the ticket opens: /ticket questions type:Support q1:What is wrong?. Several panels: /ticket panel types:Support, Report.
  6. Staff: /ticket closerequest asks if the problem is solved, /ticket transfer, /ticket list, /ticket stats (reply time, ratings). After closing, the member can rate with 1-5 stars by DM.
  7. /ticket config sets the channel name, staff ping, rating, and whether members can close their own ticket. /ticket blacklist blocks someone.

4. Levels

  1. /setup levels enabled:true channel:#levels.
  2. Write your own level-up text with message (use {user} {level} {server}) and your own picture with background.
  3. Press test to see the card. Give roles at a level with /levels addreward.
  4. /levels settings changes XP per message, cooldown and voice XP. /levels multiplier gives a role or channel more XP, /levels boost starts a double XP event, /levels ignore removes XP from a role or channel.
  5. Members get a picture card with /rank and can pick its colour: /rank color:#ff7a00.

5. Giveaways

  1. /giveaway start prize:Nitro duration:1h winners:1 (time like 30m, 2h, 1d12h). Requirements: level, messages, invites, account age, days in server.
  2. /giveaway drop prize: = the first person to press the button wins. Also edit, pause, cancel, list. Winners get a DM.
  3. Add a picture with image (PNG, JPG, GIF or WEBP) and rules or sponsor text with description.
  4. /giveaway end id: ends it now, /giveaway reroll id: picks new winners. The ID is in the giveaway footer.
  5. Extra entries by role: up to 3 roles with bonus_role + bonus_entries (for example Booster +2, Donator +3, they add up). required_role lets only that role enter and blocked_role keeps a role out. Change them later with /giveaway bonus and /giveaway block.
  6. /giveaway entries id: shows who joined, /giveaway remove id: user: removes someone. Members can press the Entries button to see who joined.

Logs, automod, custom commands and invites

  1. Logs: /setup logs channel:#logs sends everything to one channel. To split them: /setup logs type:messages channel:#msg-logs (also members, server, voice, moderation). Switch one off with off:true. Run /setup logs alone to see where each log goes. Give the bot View Audit Log so logs say who did it.
  2. Automod: /automod status opens a panel. Press Light, Standard or Strict, or pick rules in the menu. Add starter bad-word list adds common swear words in one click. Staff are ignored (use another account to test).
  3. Custom commands: /tag add name:rules text:Be kind! embed:true. Everybody uses /tag use name:rules or !rules. /tag list shows all.
  4. Invite tracker: /invites show, /invites top, /invites who user:. Needs Manage Server for the bot. Use {inviter} in welcome texts.
  5. Most active: /leaderboard type:messages period:week (also levels and invites).

Birthdays, role panels and more

  1. Birthdays: members use /birthday set. Admins run /birthday setup channel: role: message: for daily wishes.
  2. Role panels: /rolepanel title: role1: emoji1: up to 10 roles, buttons or dropdown, single to allow only one role.
  3. Voice interface: /voice interface channel:#interface posts a permanent control panel; its buttons control the voice room the member is in.
  4. Dashboard: /setup panel shows what is set up and what is missing. /setup emojis is an emoji picker.
  5. Auto-react: /setup autoreact channel: emojis: reacts to every message in a channel.
  6. Verify: /verify mode:math asks a small sum. /setup welcome dm:true also sends the welcome in DM.

Polls

  1. /poll question:Best colour? options:Red, Blue, Green minutes:30. Members vote with buttons, results update live.
  2. Leave options empty for Yes / No. Use multiple to let people pick more than one. Votes are secret unless you turn on show_names (the poll then shows 3 voters per option and a Who voted button for the full list). Start an option with an emoji, normal or animated: 🍎 Apple | :fire: Hot. Use role to let only one role vote.
  3. With minutes the poll closes by itself and shows the winner. Without it, press End poll (host or moderator).

6. Embeds and emojis

  1. /embed makes a nice message. Fill the title and text, pick a colour, add a picture, and choose the channel.
  2. Normal emojis (like 🔥) just work.
  3. To use an emoji, write :name:. Common names like :arrow:, :fire: or :announcement: become a normal emoji that works everywhere. If an emoji with that name is in your server or in JARVIS' own list, that one is used instead.
  4. If :name: stays as text, JARVIS cannot see that emoji (the bot tells you). Upload it to your server and run the command again, or paste the full emoji code: in chat send \:name: and copy what you see, like <:name:123456789>.

7. AI chat

  1. /ai channel channel:#chat: JARVIS talks with everyone in that channel. It talks ONLY in the channels you pick, everywhere else the AI is off. Pick the same channel again to turn it off there.
  2. Ask JARVIS itself: what can you do? or my tickets are not opening. It knows all its features and the common fixes.
  3. /ai teach teaches it facts about your server. /ai persona changes its personality. /ai reset makes it forget everything.
  4. Want it faster? Add your own free key: AI key guide.

8. Moderation and safety

  • /automod status shows spam, invite and bad-word protection. Turn parts on or off there.
  • /antinuke enable protects against mass bans and deletes: the nuker is punished, deleted channels and roles are restored. /antinuke preset picks light / standard / strict. Put the bot role at the top.
  • /antiraid enable stops mass-joins. /antiraid lockdown minutes:10 kicks all new joiners during an attack.
  • /setup logs sets the log channel. /warn, /timeout, /kick and /ban do what they say.

YouTube and Twitch alerts

  1. /setup youtube creator:youtube.com/@name post_in:#videos role:@Fans announces new videos (no key needed).
  2. /setup twitch streamer:name post_in:#live announces when they go live. The bot owner must add a free Twitch app key first.
  3. /setup notifications lists them. Use action:test to see a sample, action:remove to delete.

Warnings, scam links and server stats

  1. Automatic punishment for warnings: in the dashboard page Warnings choose a timeout every N warnings, and optionally a kick or a ban at a number. 0 turns a step off. Staff use /warn, /warnings and /unwarn.
  2. Scam link protection: /automod now has a rule for fake Nitro, fake Steam and look-alike Discord links. The Light, Standard and Strict presets include it.
  3. Server stats channels: in the dashboard page Server stats press Create channels for me. You get locked voice channels like “Members: 1,234” that update every 10 minutes. Needs the Manage Channels permission.
  4. Leaderboards: /leaderboard shows levels, messages or invites with a podium and page buttons.

Voice rooms

  1. /voice setup hub:#Join-to-create (a voice channel). When someone joins it, they get their own room.
  2. The room chat gets a panel with buttons: Name, Limit, Privacy, Info, Chat, Trust, Untrust, Invite, Kick, Region, Block, Unblock, Claim, Transfer, Delete. Only the room owner can press them.
  3. The bot needs Manage Channels and Move Members. The room is deleted when everyone leaves.

9. Music

/play works with song names and SoundCloud or Spotify links. YouTube links are off on most hosting because YouTube blocks them.

Something wrong?

  • A command is missing: press Ctrl+R in Discord to reload, and check that you have the permission for it.
  • “Invalid role”: pick the role from the list that appears, do not type it.
  • JARVIS cannot give a role: move the JARVIS role higher (step 1).
  • AI does not answer: run /ai status and see the AI key guide.
  • Still stuck? Ask in the support server.
