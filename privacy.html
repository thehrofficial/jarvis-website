Privacy policy

Last updated:

is a Discord bot. This page explains what information it handles when it is in your server, why, and how to have it removed.

What the bot stores

Only what its features need:

  • Server settings: the server ID and settings admins choose, such as welcome, log, suggestion, starboard and AI channel IDs, role IDs, welcome text, prefix, automod, antinuke and anti-raid settings, banned words, auto replies, vanity text and the antinuke trusted list.
  • Leveling: user ID, XP and level per server, plus level reward roles set by admins.
  • Economy: user ID, coin balance, the time of the last /daily and /work, and owned shop items per server.
  • Warnings, moderation cases and temporary bans: user IDs, the moderator's ID, the action, the reason and the time (this powers the mod history).
  • Tickets: ticket number, category, subject, who opened and who claimed it, priority, times and the close reason. A transcript of the ticket channel is generated when a ticket closes and sent to the server's log channel and to the person who opened the ticket. We do not keep the transcript in our database.
  • Reminders: the reminder text, your user ID, the channel and the time it is due. It is deleted after it is delivered.
  • AFK status: your user ID, the reason you gave and the time, until you send a message again.
  • Suggestions and starboard: the suggestion text with the author's ID, and the IDs of messages that were starred.
  • Giveaways: prize, channel and message IDs, end time, host ID and the user IDs of entrants.
  • Music: if an admin turns on 24/7 mode, the voice and text channel IDs are saved so the bot can rejoin after a restart.

What the bot reads but does not store

  • Message content. The bot reads messages to award XP, apply automod, handle AFK, run auto replies, run prefix commands and chat with the AI. Text is processed in memory and is not saved to our database. The most recent deleted and edited message in a channel is kept in memory for up to one hour for the snipe command, then discarded.
  • AI chat. When someone talks to the bot in the AI channel, mentions it, or uses /ask, that message and a short recent history of that conversation are sent to a third-party AI service to generate a reply. Do not share private information with the AI. Conversations are kept in memory only and are cleared regularly. A server admin can add the server's own AI key (/ai key). That key is stored encrypted in the database, is used only for that server's AI replies, and is deleted with /ai keyremove or when the bot leaves the server.
  • Custom status. If the vanity role is on, the bot reads members' custom status text to check for the admin's chosen text. It is not saved.
  • Server logs. If an admin sets a log channel, the bot posts message edits and deletes there, including the text. That text lives in the admin's own Discord server.
  • Music requests. Song names and links are used to find audio from public sources and are not saved.
  • Audit logs. If antinuke is on, the bot reads the server's audit log to see who deleted channels, banned members and so on.

How we use it

Only to run these features in the server where you used them. We do not sell your information, use it for advertising, or build profiles of people across servers.

Who it is shared with

Nobody, except the services needed to run the bot: Discord, the hosting provider that stores the database, the public streaming sources used to find music, and the AI service used for AI chat.

How long we keep it

  • When the bot is removed from a server, that server's stored data is deleted.
  • You can ask us to delete your personal data (levels, coins, warnings, inventory, giveaway entries, reminders, suggestions) at any time. Email us with your Discord user ID and, if you want it limited to one server, that server's ID.
  • Server admins can also remove many things themselves, for example with /unwarn, /setup clear and /autoresponder remove.

Children

Discord requires users to be at least 13 (or the minimum age in their country). The bot is not meant for anyone younger and we do not knowingly collect their data.

Security

The database is stored on the hosting provider's servers and is not publicly accessible. No system is perfectly secure, so we cannot promise absolute security.

Changes

If we change this policy we will update the date at the top. Continuing to use the bot after a change means you accept it.
