Use your own AI key

The AI chat uses a free key that is shared by all servers, so it can run out on busy days. If your server adds its own free key, your server gets its own limit, and the AI stays fast for your members.

It takes about two minutes. You need the Manage Server permission.

Step 1: get a free key

We recommend Groq: it is the fastest and has a generous free plan. Gemini also works. Sign-up rules change, so follow what the site asks.

  • Groq (recommended): open console.groq.com/keys, log in, press Create API Key, give it a name and copy the key. It starts with gsk_. Fast answers.
  • Google Gemini: open aistudio.google.com/apikey, log in with Google, press Create API key and copy it. It starts with AIza.

The key is shown only once. Copy it right away.

Step 2: add it in Discord

  1. In your server type /ai key and press Enter.
  2. A private form opens. Nobody else can see what you write.
  3. In Service write groq (best) or gemini.
  4. Paste the key. Leave Model empty.
  5. Press Submit. The bot tests the key first and only saves it if it works.

Check it with /ai status. Remove it any time with /ai keyremove. Need this guide in Discord? Use /ai keyhelp.

Good to know

  • Your key is stored encrypted. Never post it in a channel. If you did, delete it on the service's site and make a new one.
  • If your key runs out or stops working, the bot switches to the shared AI, so chat keeps going.
  • Each free plan has its own daily limit. A small server will almost never reach it.
  • Adding a key does not change anything else: facts you taught, the personality and the AI channel stay the same.

Something wrong?

  • “did not work” when saving: copy the whole key again, with no spaces, and check that you wrote the service name right.
  • Still stuck? Ask in the support server.
